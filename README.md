# Scorpion Download Manager (IDM Edition) 🦂⚡

تطبيق سطح مكتب احترافي للويندوز لتسريع وتقسيم وإدارة التحميلات على غرار **Internet Download Manager (IDM)**.

## المميزات الأساسية
- **تقسيم الملفات الديناميكي (Dynamic File Segmentation):** تقسيم الملف حتى 32 اتصال متزامن باستخدام `HTTP Range` مع ميزة سرقة العمل الديناميكية (Dynamic Work Stealing) عندما ينتهي أحد الأجزاء مبكراً.
- **الإيقاف والاستكمال (Crash-Safe Pause & Resume):** حفظ حالة كل بايت على القرص لحظياً مع إمكانية تحديث الروابط المنتهية (`Refresh Download Address`).
- **نافذة تقدم التحميل الشهيرة (IDM Progress Dialog):** رسم بياني حي للسرعة، خريطة تقسيم الأجزاء الـ 16/32، وجدول تفصيلي لكل اتصال.
- **مراقبة الحافظة والربط بالمتصفح:** التقاط تلقائي للروابط المنسوخة + خادم محلي `127.0.0.1:19615` لاستقبال الروابط من المتصفح.
- **الجدولة والطوابير ومحدد السرعة وفحص SHA-256 / MD5.**

## التشغيل والبناء
- لتشغيل البرنامج مباشرة:
  ```bash
  npm start
  ```
- لبناء ملف التسطيب الرسمي للويندوز (`Scorpion-Setup-1.0.0.exe`):
  ```bash
  npm run dist
  ```
